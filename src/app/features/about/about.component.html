RxJS Operators in Action

On load, this component fires two parallel HTTP requests (Posts + Users) using mergeMap and map, then merges the results. Check the browser console to see the output.

getAllPosts().pipe(mergeMap(posts => getAllUsers().pipe(map(users => [...posts, ...users]))))
